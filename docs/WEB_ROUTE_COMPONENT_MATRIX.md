# OTONOM public route and component matrix

Every route below is rendered for both `/ar` (RTL) and `/en` (LTR). The design v2 layer (`v2.css`, DR-099) is loaded once by the shared site layout over the earlier CSS, so the same tokens, fonts, shell, focus treatment and responsive rules apply without duplicating route logic. The locked Hybrid 03 logo files are unchanged.

Language switch: `LangSwitch` builds its link with `localeSwitchHref()` (`lib/locale-switch.ts`), keeping only allow-listed, validated state: the portfolio query on `/projects`, `package` and `service` on `/start-project`, and a `#package-{id}` anchor on `/smart-home/packages`.

Shared components: `SiteHeader` (wordmark, nav pills, 1000px drawer, Book a visit), `SiteFooter` (phone and WhatsApp), `BrandLogo`, `Swash`/`SwashText`, navigation menus, buttons, fields, cards, breadcrumbs, empty states, product cards and section wrappers. Shared visual source: `app/web/src/app/(site)/v2.css` over `site.css`/`hybrid03.css`; portfolio refinements remain in `portfolio.css`. Unknown language-code paths (e.g. `/xx`) render the Arabic localized 404 inside the shell (proxy rewrite, status 404).

Operational routes (`/staff/login`, `/admin`, Payload/API and GraphQL surfaces) retain their independent authentication and security presentation and are not rebranded by the public-site layer.
