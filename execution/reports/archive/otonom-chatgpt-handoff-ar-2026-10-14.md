  - موقع B2B ثنائي اللغة (عربي RTL / إنجليزي).
  - workflow نشر بمراجعة.
  - نموذج RFQ من غير رفع ملفات (P-A).
  - CRM ومسار فرص البيع.
  - توقيع العقود والـ attribution والـ KPI.
  - تسجيل دخول الموظفين بـ MFA.
  - قدرات W1 التجارية (متجر وضمان)، **مقفولة من السيرفر** طول ما المرحلة PREVIEW.

## 3. إزاي تشغّله (محلياً بس)
1. شغّل PostgreSQL المحمول بـ `pg_ctl`، من غير Windows service. الأوامر في `app/README.md`.
2. نفّذ الأوامر دي:
   ```bash
   cd D:/otonom/app
   pnpm install --offline
   pnpm db:setup
   cd web && npx payload migrate && npx tsx scripts/seed.ts
   npx next build
   OTONOM_TRUST_PROXY=1 npx next start -H 127.0.0.1 -p 3301
   pnpm test:domain
   pnpm test:http
   ```
3. بيانات دخول الموظفين الاصطناعية موجودة في `app/.local-secrets/dev_users.json`. **ممنوع تتنسخ أو تتشارك.**

## 5. قواعد تقنية اتعلمناها (لازم تتطبق)
- كل collection في Payload لازم يبقى ليها `access` صريح. والحقول الحساسة ليها field access.
- `readOnly` في الأدمن بيقفل الواجهة بس، فالحقول النظامية بتترجع لقيمتها في الـ hooks.
- متعملش custom endpoint تحت اسم collection (زي `/api/opportunities/...`)، علشان Payload بيبلعه. استخدم `/api/workspace/...` أو `/api/admin/...`.
- أي كتابة على `domain.*` تعدي على `@otonom/domain`، ومعاها `correlationId`.
- دور قاعدة بيانات الـ CMS ملوش أي صلاحية على schema `domain`.
- الـ bidi في الحقول: `dir="ltr"` للتليفون والإيميل والتواريخ والأكواد. و`<bdi>` حوالين أي نص لاتيني جوه نص عربي.
